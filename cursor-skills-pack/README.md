# Precivox Cursor Skills Pack

Skills globais extraídas do servidor Precivox (sem as 8 archive-candidates).

## Instalar na sua conta/máquina (todos os projetos)

```bash
npx skills add ./cursor-skills-pack --all -g -y -a cursor
# ou, após merge na main / neste branch no GitHub:
npx skills add romuloroldao/PRECIVOX- --all -g -y -a cursor
```

Isso grava em `~/.agents/skills` e/ou `~/.cursor/skills` (escopo **user/global**).

Depois: **Developer: Reload Window** no Cursor.
